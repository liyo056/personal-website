# 苏云奕 · 个人主页网站

> 一个用纯 HTML/CSS/JS 手写的个人介绍网站，糖果配色、响应式设计、支持深色模式。
> 项目目标：作为大四毕业求职时的个人名片，展示个人信息、学校背景、项目经历、课程与证书。

## 项目简介

本项目是计算机专业课程「个人介绍网站」的课程作业，同时也是我未来求职时对外展示的个人主页。

网站采用**纯原生技术**实现，无任何框架依赖，打开即可运行：

- **HTML5** — 语义化结构
- **CSS3** — 自定义属性（CSS Variables）实现多主题配色、响应式布局、动画
- **原生 JavaScript** — 主题切换、滚动动画、相册灯箱、导航高亮等功能

## 功能特性

| 功能 | 说明 |
|------|------|
| 🎨 糖果配色 | 多巴胺风格配色，CSS 变量一键换色 |
| 🌙 深色模式 | 支持明暗主题切换，localStorage 记忆用户偏好 |
| 📱 响应式设计 | 手机 / 平板 / 桌面端自适应，移动端汉堡菜单 |
| 🖼️ 相册灯箱 | 点图放大、左右翻页、键盘方向键操作 |
| ✨ 滚动动画 | IntersectionObserver 实现的入场动画 |
| 📋 一键复制 | 复制抖音号等快捷操作 |
| ♿ 无障碍 | 语义化标签、焦点样式、键盘可操作 |

## 本地运行

本项目是纯静态网站，**无需安装任何依赖**，直接用浏览器打开 `index.html` 即可：

```bash
# 方式一：直接双击 index.html 文件

# 方式二：用 Python 起一个本地服务器（推荐，便于预览）
cd personal-website
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

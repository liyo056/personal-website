## 方案一：GitHub Pages（静态托管）

### 原理

GitHub Pages 是 GitHub 提供的免费静态网站托管服务。把项目推送到 GitHub 仓库后，GitHub 会自动把仓库内容托管到 `https://用户名.github.io/仓库名/` 这样的公网地址上。

### 步骤

1. **注册 GitHub 账号**（如已有则跳过）
   - 访问 <https://github.com>，注册账号。

2. **创建仓库**
   - 点击右上角 `+` → `New repository`
   - 仓库名建议：`personal-website`（或 `用户名.github.io`，后者可直接用根域名）

3. **推送代码**
   ```bash
   git init
   git add .
   git commit -m "初始化个人主页网站"
   git branch -M main
   git remote add origin https://github.com/你的用户名/personal-website.git
   git push -u origin main
   ```

4. **开启 Pages**
   - 进入仓库 → `Settings` → `Pages`
   - `Source` 选择 `Deploy from a branch`
   - `Branch` 选择 `main`，目录选择 `/ (root)`
   - 保存后等待 1-2 分钟，即可通过 `https://你的用户名.github.io/personal-website/` 访问。

### 优缺点

- ✅ 免费、稳定、无需维护服务器
- ✅ 天然配合 git 版本管理
- ❌ 只能托管静态内容（本项目是纯静态，正好满足）

## 方案二：云服务器 + Nginx（掌握服务器部署）

> 老师希望我们掌握「服务器的简单部署」，这一步建议用学生机实操一遍。

### 购买学生机

- 阿里云「云翼计划」或腾讯云「校园计划」，学生认证后约 100 元/年，配置 1核2G 足够。
- 系统选择 **Ubuntu 22.04** 或 **CentOS**。

### 部署步骤（以 Ubuntu 为例）

1. **连接到服务器**
   ```bash
   ssh root@你的服务器公网IP
   ```

2. **更新系统并安装 Nginx**
   ```bash
   sudo apt update
   sudo apt install -y nginx
   ```

3. **上传网站文件**
   ```bash
   # 在本地执行，把文件传到服务器
   scp -r personal-website/* root@你的服务器公网IP:/var/www/html/
   ```

4. **启动并检查 Nginx**
   ```bash
   sudo systemctl start nginx
   sudo systemctl enable nginx   # 开机自启
   systemctl status nginx        # 查看运行状态
   ```

5. **浏览器访问** `http://你的服务器公网IP` 即可看到网站。

### 常用命令速查

| 命令 | 作用 |
|------|------|
| `systemctl start nginx` | 启动 Nginx |
| `systemctl stop nginx` | 停止 Nginx |
| `systemctl restart nginx` | 重启 Nginx |
| `systemctl status nginx` | 查看状态 |
| `nginx -t` | 检查配置语法 |
| `tail -f /var/log/nginx/access.log` | 查看访问日志 |

### 进阶（可选）

- **绑定域名**：购买域名后，在 DNS 解析到服务器 IP，Nginx 配置 server_name。
- **HTTPS**：用 Let's Encrypt 免费证书（certbot）开启 https。

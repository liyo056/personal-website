# 项目规划

## 一、需求分析

### 老师要求

1. **开发能力**：本项目不侧重锻炼开发能力，允许使用 AI 辅助实现。
2. **网站定位**：用于大四毕业求职，需包含个人信息、学校信息、项目经历、课程、培训证书等。
3. **文档规范**：本项目涉及的所有文档，统一使用 Markdown 编写。
4. **版本管理**：使用 git 工具管理版本，记录关键提交信息与过程。
5. **部署上线**：部署到云服务，可在公网访问，掌握服务器简单部署。

### 需求拆解

| 需求 | 实现方式 | 状态 |
|------|---------|------|
| AI 辅助开发 | 使用 WorkBuddy AI 辅助编写与优化代码 | ✅ |
| 求职向内容 | 个人信息 / 学校 / 项目 / 课程 / 证书 | 🔄 规划中 |
| Markdown 文档 | README + docs 目录全部使用 .md | ✅ |
| git 版本管理 | 本地 git 仓库 + 规范 commit | ✅ |
| 公网部署 | GitHub Pages + 云服务器 Nginx | 🔄 进行中 |

## 二、技术选型

| 项目 | 选择 | 理由 |
|------|------|------|
| 前端技术 | 纯 HTML/CSS/JS | 无框架依赖，部署简单，加载快 |
| 版本管理 | git | 老师要求，标准工具 |
| 代码托管 | GitHub | 免费、支持 Pages 静态托管 |
| 部署方式 | GitHub Pages + 云服务器 Nginx | 先免费上线，再掌握服务器部署 |

## 四、风险与注意事项

- **隐私**：公网部署后个人信息（抖音号、照片等）对所有人可见，需自行评估可接受范围。
- **图片体积**：单文件版 HTML 将图片 base64 内嵌达 4.3MB，建议使用图片目录引用的方式以加快加载。
- **域名**：GitHub Pages 提供 `用户名.github.io` 免费子域名；如需自定义域名可后续绑定。
